# Изменения

## 2026-10-12

- Сейв прежней версии: Git-метка `stable-2026-10-12`, исходники и локальная SQLite-копия.
- Компактное управление с отдельным сервисным меню.
- Поиск по имени и части username, выбор нескольких совпадений кнопками, сохранение фильтра при перелистывании.
- Участники отсортированы по реальной активности в группе; доступна сортировка по имени.
- Исправление текста заметок и плейсментов, смена Small / Big, подтверждённое удаление.
- История изменений с предыдущим содержанием, автором и датой; восстановление удалённых записей.
- Проверка версии записи перед изменением: устаревшее подтверждение не затирает более новое исправление.
- Плейсменты, учтённые при подтверждении роли, защищены от изменения.
- Редактирование черновика до сохранения; неизвестная команда не сбрасывает текущую форму.
- Только доступные подтверждения ролей; отдельный список участников с достигнутым порогом.
- Месячная статистика без ожидания архивирования; сравнение сопоставимых периодов.
- Единый рейтинг по категориям и вкладу с объяснением баллов.
- Просмотр прошлой календарной недели, состояние автоотчёта и подтверждённое выключение.
- Старые команды записи открывают кнопочный интерфейс; немедленных изменений больше нет.
- CSV включает участников с одними заметками и защищает имена от интерпретации как формул.
- Удалены старые неиспользуемые генераторы экранов и дублирующие команды изменения данных.

Схема обновляется автоматически при запуске: добавляется таблица `record_changes`. Существующие записи сохраняются.
