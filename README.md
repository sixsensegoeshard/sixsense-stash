# 301secrets Tracker

Telegram-бот для учёта активности в группе: статистика, плейсменты, прогресс ролей и отчёты. Основной интерфейс — кнопки в личном чате с ботом.

## Интерфейс

Открой бота и отправь `/start` или `/menu`:

- **Моя статистика** — компактная карточка, переключение между 7 днями, 30 днями, месяцем и всем временем.
- **Мой профиль** — сводка активности, плейсменты, история месяцев и прогресс роли.
- **Участники** (администратор) — список с постраничной навигацией, поиск по точному `@username` или ID; можно переслать сообщение с открытым автором.
- **Рейтинг** (администратор) — выбор периода и категории кнопками.
- **Управление** (администратор) — отчёты, кандидаты, CSV, состояние трекера, копия базы и месячный архив.

В карточке участника администратор добавляет плейсмент или заметку по шагам: тип → текст → проверка → подтверждение. Выдача роли и отмена записи также требуют подтверждения. Повторное нажатие «Сохранить» не добавляет вторую запись. `/cancel` и кнопка отмены завершают ввод; незавершённая форма истекает через 15 минут. После перезапуска незавершённый ввод нужно начать заново.

В меню команд осталось 4 пункта для участников и 6 для администраторов. Старые команды (`/stats @user`, `/place`, `/note` и другие) поддерживаются для совместимости, но основные действия доступны в кнопках. `/stats` и `/profile` без аргументов показывают собственную карточку.

Навигация меняет одно сообщение. Запрос из группы открывает карточку в личке; чтобы бот мог написать, сначала нажми Start. Кнопки привязаны к пользователю, открывшему карточку. Чужие профили, заметки, рейтинг и администрирование доступны только ID из `ADMIN_IDS`.

## Как считается активность

- Аудио и музыкальные документы (`.wav`, `.mp3`, `.mid` и т. д.) — лупы.
- ZIP / RAR / 7Z и другие архивы — архивы.
- Фото, видео, GIF и видеокружки — медиа.
- Текст и голосовые — сообщения. Другие документы — файлы.
- `#opportunity` — дополнительный признак, не отдельное действие; похожие теги вроде `#opportunity_extra` не считаются.

Команды, сообщения ботов, служебные события и другие чаты не учитываются. Для задержанных обновлений используется исходная дата Telegram. Повторная доставка одного сообщения не увеличивает счётчик. Дни и текущая серия считаются в `BOT_TIMEZONE`; статистика ограничена `TRACK_CHAT_ID`.

Telegram не передаёт всю старую переписку: бот считает полученные обновления. Изменения классификации действуют для новых сообщений; старые записи автоматически не переименовываются. Роли в Telegram выдаются вручную, кнопка подтверждения сохраняет историю и начинает новый цикл соответствующей шкалы.

## Требования

- Python 3.11 или новее
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)
- ID администраторов и отслеживаемого чата

## Установка

```bash
git clone https://github.com/sixsensegoeshard/sixsense-stash.git
cd sixsense-stash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

На Windows активация окружения выглядит так:

```powershell
.venv\Scripts\Activate.ps1
```

## Настройка `.env`

Открой `.env` и заполни:

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота от BotFather |
| `ADMIN_IDS` | ID администраторов через запятую |
| `TRACK_CHAT_ID` | ID группы или супергруппы для отслеживания |
| `DB_URL` | URL базы данных; по умолчанию SQLite-файл `tracker_v3.db` |
| `BOT_TIMEZONE` | Часовой пояс для отчётов, например `Europe/Moscow` |
| `REQUIRE_TRACK_CHAT_ID` | `1` — требовать чат, `0` — разрешить запуск без него |

Дополнительные пороги статистики находятся в `.env.example`.

## Настройка Telegram

1. Создай бота через BotFather и скопируй токен в `BOT_TOKEN`.
2. Добавь бота в нужную группу.
3. Выдай ему права администратора, если боту нужно видеть обычные сообщения.
4. Узнай числовой ID группы и укажи его в `TRACK_CHAT_ID`.
5. Узнай свой Telegram ID и укажи его в `ADMIN_IDS`.

Не публикуй `.env`: в нём находится секретный токен бота. Этот файл уже добавлен в `.gitignore`.

## Запуск

```bash
source .venv/bin/activate
python trackerbot.py
```

Остановка — `Ctrl+C`.

После обновления кода останови старый процесс и запусти бота заново — только так он загрузит изменения и обновит меню команд Telegram. Одновременно должен работать один экземпляр с этим токеном.

## Проверки

```bash
python -m unittest discover -s tests -v
python -m py_compile trackerbot.py tracker_ui.py
python -m pip check
```

Тесты используют искусственные Telegram-обновления, подмену API и SQLite в памяти. Они не читают рабочий `.env`, не подключаются к Telegram и не меняют реальную базу.

## Структура

- `trackerbot.py` — исходный код бота.
- `tracker_ui.py` — экраны, кнопки и пошаговый ввод.
- `tests/` — проверки учёта, поиска, доступа и навигации.
- `.env.example` — пример настроек без секретов.
- `requirements.txt` — зависимости Python.
- Файл из `DB_URL` — локальная база; существующий путь из `.env` сохраняется.
- `backups/` — локальные резервные копии, не загружаются на GitHub.
